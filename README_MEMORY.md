This package is the persistent memory layer for the football prediction game.

## Most important files

1. `.github/copilot-instructions.md`
   Global rules for Copilot.

2. `AGENTS.md`
   Agent-level guardrails.

3. `docs/GAME_DESIGN.md`
   Product identity and differentiator.

4. `docs/GAME_RULES.md`
   Game behavior.

5. `docs/SCORING_SYSTEM.md`
   Scoring principles.

6. `docs/ARCHITECTURE.md`
   Architecture principles.

7. `docs/DATA_MODEL.md`
   Domain/data concepts.

8. `docs/DECISIONS.md`
   Permanent approved decisions.

9. `docs/ROADMAP.md`
   Development state.

## Golden rule

If a future AI session cannot understand an important product decision from the repository itself, that decision is not documented well enough yet.
